# Telegram Crypto Scanner

Alert-only Binance USDT spot market research scanner. It does not place trades and does not guarantee future price movement or profitability.

## Status

This repository is being initialized. Do not rely on it for investment decisions until the scanner, automated tests, live API checks, Telegram delivery, and historical evaluation have been completed.

## Security

Never commit Telegram bot tokens or other secrets. Configure credentials only as GitHub Actions repository secrets after reviewing the workflow.

## Validation

Passing unit tests proves only tested software behavior. It does not establish that signals are profitable. Performance assessment requires a reproducible historical backtest with fees, slippage, out-of-sample evaluation, and paper-trading validation.
